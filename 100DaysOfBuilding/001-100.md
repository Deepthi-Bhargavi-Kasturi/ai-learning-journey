## Day 01 — Training an LLM with Hugging Face

Today I went through a basic tutorial on training an LLM using the Hugging Face course.

### What I learned

- `load_dataset()` loads the dataset. A dataset can contain multiple splits such as `train` and `test`, which is why `split="train"` can be used to select the required split.
- Before training, the text needs to be tokenized.
- Tokenization produces `input_ids` and `attention_mask`, which are used as inputs by the model.
- `remove_columns` can be used to remove the original dataset columns after preprocessing.
- `map()` can apply a preprocessing/tokenization function to the dataset.
- `batched=True` means the preprocessing function receives a batch of examples instead of processing one example at a time.
- `truncation=True` allows sequences longer than the specified maximum length to be truncated.
- `max_length=512` sets the maximum sequence length for the tokenizer.
- `train_test_split(test_size=0.1)` creates a split where 90% of the data is used for training and 10% for testing.
